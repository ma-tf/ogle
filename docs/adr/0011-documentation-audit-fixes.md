# ADR-0011: Documentation audit fixes

**Status:** Accepted

## Context

ADR numbering jumped from 0010 (unit test conventions) to 0012 (raw dimensions and message integrity)
with no ADR-0011. This ADR fills that gap and documents the findings of the documentation audit
performed by the Scrivener tool (issue 110).

## Decisions

- No architectural decisions were recorded between ADR-0010 and ADR-0012 that warranted a separate ADR.
  The jump in numbering was an oversight.
- Documentation discrepancies discovered by Scrivener are filed as issues and fixed directly in the
  affected docs; they do not warrant individual ADRs.

## Consequences

- Readers will no longer wonder about the missing number.
- Future documentation audits should indicate the affected ADR in their findings when relevant.
